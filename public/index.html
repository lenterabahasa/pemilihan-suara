Sistem Pencegahan Kecurangan Berlapis

Dirancang untuk menjamin prinsip "Satu pemilih, satu suara, suara rahasia, hasil dapat diaudit."

🔒

Kerahasiaan Suara Mutlak

Data pilihan kandidat dipisahkan dari identitas pemilih di database. Tidak ada relasi user_id pada tabel suara, sehingga pilihan Anda anonim.

⚡

Transaksi Atomik Suara Tunggal

Backend memverifikasi status pemilih dengan transaksi basis data atomik (ACID). Upaya memilih dua kali akan langsung digagalkan dan ditandai.

🛡️

Deteksi Anomali Real-Time

Mesin Anti-Fraud memantau serangan brute force, percobaan akses terlarang, serta lonjakan request mencurigakan dengan klasifikasi risiko multi-tier.

📜

Audit Log Kriptografis

Setiap catatan audit log menggunakan rantai hash SHA-256 (Hash Chained). Setiap modifikasi ilegal akan langsung terdeteksi oleh Auditor.
